# 0001. 마케터 창구는 웹(요청 + 대시보드), 노션은 기록 보관

- 상태: 채택 · 2026-10-14

## 맥락
마케터는 Claude 계정이나 개발 도구 없이 agent를 써야 한다. 후보는 ① Claude Code 플러그인 ② 노션 DB를 요청 큐로 쓰기 ③ 전용 웹 페이지였다.

## 결정
요청 폼·진행 상태·결과 승인·대시보드를 한 웹 페이지에서 제공한다. 노션은 요청 창구가 아니라 설계 문서와 일일 리포트를 보관하는 곳으로 둔다.

## 결과
- 마케터는 주소 하나만 알면 된다. agent별 입력 폼으로 요청이 구조화되어 라우팅 정확도가 올라간다.
- 대신 저장·파일 첨부·로그인을 직접 구현해야 한다 (→ 0002).
- 플러그인 방식은 쓰는 사람마다 Claude Code가 필요해 기각했다.
