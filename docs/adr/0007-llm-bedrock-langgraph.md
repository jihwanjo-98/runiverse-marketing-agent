# 0007. LLM은 Bedrock + LangChain · LangGraph, 리서치는 Claude Code 배치

- 상태: 채택 · 2026-10-15 · [0003](0003-llm-backend-claude-code.md) 대체 (리서치 배치 부분만 유지)

## 맥락
0003은 비용 0을 위해 운영자의 Claude Code 구독(`claude -p`)으로 모든 agent를 돌리는 설계였다. 검토 결과 두 가지 문제가 있었다.
- 팀원 요청을 운영자 개인 구독으로 상시 처리하는 형태가 된다.
- `claude -p`는 LangChain 같은 표준 오케스트레이션 도구와 맞지 않는다.

대안으로 무료 API와 로컬 LLM도 비교했다.
- 무료 API: 일부가 입력을 학습에 쓰고, 한도가 자주 바뀐다.
- 로컬 LLM: 운영 PC(Intel Arc 140V 내장 GPU, 공유 메모리 18GB)로는 7~14B 모델이 한계이고 응답이 느리다.

## 결정
- **요청 처리 agent는 AWS Bedrock의 Claude를 호출한다.** 경량 작업은 Haiku, 생성(A4) · 검증(A5)은 Sonnet을 기본으로 하고, 최종 모델은 샘플 평가로 정한다.
- **모델 연결은 LangChain 채팅 모델 인터페이스**(`langchain-aws`)를 쓴다. 0003의 자체 `LLMBackend` 인터페이스는 만들지 않는다. 같은 역할의 추상화를 두 겹으로 두지 않기 위해서다.
- 구조화 출력은 `with_structured_output(pydantic 모델)`로 강제한다.
- **작업 하나 안의 흐름은 LangGraph**로 구성한다. 예: 라우팅 분기, A4 ↔ A5 수정 루프, 병렬 → 합류.
- **작업 사이의 상태와 사람 승인 대기는 DB**가 맡는다. 몇 시간 ~ 며칠 걸리는 승인을 그래프 안에 붙잡아 두지 않는다.
- **리서치(A1 · A2)는 운영자 PC의 Claude Code 예약 실행**으로 웹 검색해 적재한다. 운영자 본인의 정기 작업이므로 구독 사용 범위에 맞다. 래퍼 스크립트가 결과를 검증한 뒤 API로 올린다 (0008).
- agent별 모델은 설정 파일로 고른다. 로컬 모델(Ollama)로 바꾸는 것도 설정으로 가능하다.

## 비용 (추정)
- 8주 기준: A4 · A5 Sonnet + 나머지 Haiku = 약 $52.
- 리서치는 구독으로 처리해 추가 비용이 없다.
- AWS Budgets 월 예산 알림과 API의 하루 요청 상한(0008)으로 이중 제한한다.

## 결과
- 모델 객체 한 줄만 바꾸면 Bedrock · Anthropic API · 로컬 모델을 오갈 수 있다. 그래프 · 상태 · 실패 처리 코드는 그대로다.
- AWS 키는 Bedrock 호출 권한만 가진 IAM 사용자의 키를 `worker/.env`에만 둔다. 루트 키는 쓰지 않는다.
- 확인 필요: 서울 리전에서 Claude 5.5 사용 가능 여부, 글로벌 · 리전 엔드포인트 선택(리전은 10% 할증), Bedrock 배치 할인 적용 여부.
