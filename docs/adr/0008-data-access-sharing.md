# 0008. 데이터 저장 · 공유, Notion MCP, 팀 계정 로그인

- 상태: 채택 · 2026-10-15 · [0002](0002-vercel-supabase.md) · [0006](0006-fastapi-gateway.md) 인증 부분 대체

## 저장과 공유
- 모든 데이터는 Supabase에 저장하고 읽기 · 쓰기는 FastAPI만 한다 (0006 유지).
- **리서치**: 래퍼 스크립트가 Claude Code 결과를 `packages/contracts` 모델로 검증한 뒤 워커 토큰으로 API에 올린다. 출처 URL 기준으로 중복을 제거한다. 팀원 모두 웹에서 조회한다.
- **요청**: 대화 스레드로 관리한다.
  - 사용자 입력, agent 질문, 사용자 답변, 결과를 메시지로 쌓는다.
  - 각 결과에 사용한 근거(리서치 항목 · 노션 페이지 · 업로드 파일)를 함께 기록한다.
- **실행 기록**: agent 실행마다 모델 · 토큰 · 비용 · 응답 시간 · 성공 여부를 남긴다. 비용 관리와 모델 비교의 근거로 쓴다.
- **파일**: Supabase Storage 비공개 버킷에 둔다. API가 서명 URL을 발급하고, 브라우저는 그 URL로만 올리고 받는다.
- **성과 대시보드**: 광고 집행 시점에 구축한다. 그 전까지 홈은 최근 요청과 최신 리서치로 구성한다.

## Notion MCP
- 워커가 MCP 클라이언트로 운영자 PC의 로컬 Notion MCP 서버에 연결해, 팀 문서를 agent의 참고 자료로 쓴다.
- 통합(integration)은 **읽기 전용**으로 만들고, 지정한 팀 페이지만 공유한다.
- 노션 내용은 데이터로만 취급하고, 안의 지시문을 따르지 않는다. 원문은 DB에 복사하지 않고, 참고한 페이지의 제목 · 링크만 남긴다.
- 일일 리포트를 노션에 쓰는 기능은 쓰기 범위를 해당 페이지로 제한한 별도 통합으로 나중에 추가한다.
- 확인 필요: Notion MCP 서버의 통합 토큰 방식 지원 범위.

## 접근 방식: 팀 공용 계정 + 관리자 계정
팀원 3명, 권한 구분 최소. Vercel 무료 플랜에는 사이트 비밀번호 보호가 없다. Bedrock 사용으로 요청마다 비용이 생기므로 주소만 숨기는 방식은 쓰지 않는다.

- 계정은 두 종류로 둔다.
  - `member`: 팀 공용 아이디 · 비밀번호. 조회 · 요청 · 답변 · 승인.
  - `admin`: 운영자 전용. member 권한 + 관리자 페이지.
- 비밀번호는 해시로 DB에 저장한다. 로그인과 역할 검사는 FastAPI가 한다.
- **브라우저는 FastAPI를 직접 호출하지 않는다.**
  - 브라우저 → Next.js 서버 → FastAPI 순서로 호출한다.
  - 세션 토큰은 httpOnly 쿠키에 담고, Next.js 서버가 FastAPI에 전달한다.
  - 그래서 웹과 API 도메인이 달라도 CORS · 쿠키 문제가 없다.
- 요청 작성자 표시는 "작성자 이름" 입력으로 한다. 공용 계정이라 보안 식별은 아니다.
- 비용 안전장치로 API에 하루 요청 상한을 둔다.

### 관리자 페이지 초기 범위
| 기능 | 내용 |
|---|---|
| 계정 | 팀 계정 비밀번호 변경 (변경 시 기존 세션 무효화) |
| 운영 설정 | 하루 요청 상한, agent별 모델 설정 확인 |
| 사용량 · 비용 | agent · 모델별 호출 수, 토큰, 비용, 실패율 |
| 작업 큐 | 실패하거나 멈춘 작업 재시도 · 취소 |
| 리서치 배치 | 최근 실행 결과, 수집 건수, 오류 |
| 캠페인 | C1~C4 캠페인 카드 관리 |

## 결과
- 0006의 "Supabase Auth 로그인 토큰 + 이메일 허용 목록"은 쓰지 않는다. 웹에는 Supabase 공개 키도 두지 않는다.
- FastAPI가 받는 인증은 세 가지다.
  - 웹 서버 토큰: Next.js 서버만 API를 부를 수 있게 한다. 로그인 시도도 이 토큰이 있어야 해서 API를 직접 두드리는 공격을 막는다.
  - 세션 토큰: member · admin 역할 판별. 웹 서버 토큰과 함께 온다.
  - 워커 토큰: 로컬 워커와 리서치 배치용.
- 로그인 시도 횟수 제한을 둔다 (공용 비밀번호 추측 방지).
