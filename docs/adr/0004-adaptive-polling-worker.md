# 0004. 로컬 워커가 1분 적응형 폴링으로 작업을 가져감

- 상태: 채택 · 2026-10-14

## 맥락
워커(LangGraph · agent 실행)는 운영자 PC에서 돈다. LLM은 Bedrock을 호출한다 (0007). 집 PC에는 공개 주소가 없어 푸시(웹후크)를 받기 어렵다.

## 결정
상주 워커 루프가 근무 시간(09~20시)에는 60초, 그 외에는 600초마다 FastAPI(`POST /worker/jobs/claim`)에 작업을 요청한다. API는 Postgres `FOR UPDATE SKIP LOCKED`로 한 작업을 한 번만 내주도록 보장한다 (0006).

## 근거
- 폴링은 API 조회일 뿐 LLM 비용이 들지 않는다. LLM은 새 작업이 있을 때만 호출된다.
- 체감 지연은 처리 시간(수십 초~수 분)이 좌우한다. 60초 아래로 줄여도 효과가 작다.
- PC는 바깥으로만 요청하므로 포트 개방이 필요 없다.

## 결과
- PC가 꺼져 있으면 처리되지 않는다. 화면에 "접수됨, 보통 10분 안에 처리" 안내를 둔다.
- 알림(푸시)은 범위에서 제외한다.
