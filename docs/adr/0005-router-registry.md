# 0005. 라우터 + agent 레지스트리, 숫자는 코드 · 판단은 LLM

- 상태: 채택 · 2026-10-14

## 맥락
마케터 요청은 형식이 다양하다. 새 agent를 추가해도 라우팅 코드를 고치지 않아야 하고, 요청 본문의 지시로 시스템이 엉뚱하게 움직이면 안 된다.

## 결정
- 각 agent는 레지스트리에 카드(할 수 있는 일, 필요한 입력, 허용 도구)로 등록한다.
- 라우터 A0는 요청을 읽고 `{intent, agent, params, missing, confidence}`를 낸다. 레지스트리 밖의 선택지는 없다.
- 필요한 입력이 빠졌거나 확신도가 낮으면 실행하지 않고 되묻는다.
- 지표 계산·게이트 판정·규칙 검사·링크 생성은 결정론적 코드, 해석·글쓰기·검증 판단은 LLM이 맡는다.

## 결과
- 요청은 데이터일 뿐 명령이 아니다. 예산·입찰·광고 ON/OFF를 바꾸는 도구는 아예 존재하지 않는다.
- LLM이 숫자를 지어낼 여지가 없고, 사용량이 줄어든다.
